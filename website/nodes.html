When uptime counts

Uptime counts only while the node is running, your computer is awake and online, and the network receives real Ed25519 signed block votes and heartbeats. You do not need to stay signed into this website, and this browser tab does not need to stay open.

Power Configuration: The screen can go to sleep, but not the actual computer.
