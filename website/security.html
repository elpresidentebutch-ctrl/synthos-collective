Official installer details

SYNTHOS security and node installer transparency

This page explains the SYNTHOS validator node installer in plain language so operators, email systems, and search engines can understand what is being installed.

The SYNTHOS node installer is user-authorized software for running a validator service. It does not ask for passwords, does not access wallets, does not mine cryptocurrency, and does not open inbound firewall ports.

What gets installed

The installer creates a Windows Service named SynthosNode. The service runs in the background and starts automatically with Windows while the computer is on.

What the node sends

The service sends outbound HTTPS heartbeats to the SYNTHOS backend. Each heartbeat is signed with the node's local Ed25519 key.

Where keys are stored

The service stores its local node key and status under C:\ProgramData\SynthosNode. The private key should stay on the operator's computer.

What it does not do

It does not request credentials, read browser passwords, access wallets, mine, open inbound ports, or require a SYNTHOS website login.

Operator controls

Install, verify, or remove the node

Install

Download the installer from the official SYNTHOS backend. Windows will ask for Administrator approval because the node is installed as a service.

Download Installer View Node Dashboard

Remove

To stop and remove the Windows Service later, open PowerShell as Administrator and run:

Stop-Service SynthosNode
sc.exe delete SynthosNode
