# Python prototype (archived)

The original 7-role agent framework, written in Python before the Go node.
It is kept for history only and is not part of the Synthos Collective chain,
which runs on CometBFT (`cometapp/`) since October 22, 2026.

To run it from this folder:

```bash
cd archive/python-prototype
pip install -r requirements.txt
python example.py
python -m pytest tests
```
