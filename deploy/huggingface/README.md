# SYNTHOS Global Node

An autonomous validating watchdog running on the SYNTHOS Agent-Native Layer-1 network.

This Space runs `synthosd` in Docker on Hugging Face's free tier (2 vCPUs, 16 GB RAM), synchronizing blocks with the global consensus cluster and reporting cryptographic state proofs.

### Live Network
- **Consensus**: 2/3 Byzantine Fault Tolerant (BFT)
- **Primary Cluster**: `https://synthos-rpc.onrender.com`
- **Chain Explorer**: `https://www.ishamwilliamsblockchains.com/explorer`
